# // ep. 016 · Ordenamiento burbuja en Python (bubble sort): el más fácil de entender

**Curso:** [Introducción a los Algoritmos](../../) · **Módulo 4 — Búsqueda y ordenamiento** · estreno el 5 feb 2027

Ordenas cien mil números con sorted, la función de Python: dos centésimas de segundo. Los ordenas con el algoritmo de hoy, el ordenamiento burbuja: unos quince minutos. Los dos dan exactamente la misma lista. Hoy programas tu primer algoritmo de ordenamiento y entiendes por qué es tan lento.
