# // ep. 024 · Divide y vencerás en Python: merge sort y búsqueda binaria recursivos

**Curso:** [Introducción a los Algoritmos](../../) · **Módulo 5 — Recursión y divide y vencerás** · estreno el 2 abr 2027

Nueve monedas idénticas, una falsa que pesa un poquito menos y una balanza de platillos: ¿cuántas pesadas necesitas para encontrarla? Hasta cuatro, si comparas de dos en dos; dos, si sabes dividir. Hoy vemos la estrategia de divide y vencerás (dividir, conquistar y combinar), escribimos la búsqueda binaria de forma recursiva, miramos con otros ojos el merge sort del ep. 018 y vemos cuándo dividir sí ayuda y cuándo no.
